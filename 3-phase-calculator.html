The main 3 phase calculator formula is P = 1.732 x V x I x PF. P is active power or real power in watts, V is line-to-line voltage, I is line current in amperes, and PF is power factor. Apparent power calculation uses S = 1.732 x V x I.

Real PowerP = 1.732 x V x I x PF Apparent PowerS = 1.732 x V x I Reactive PowerQ = square root(S^2 - P^2)

3 Phase Calculation Formula

The 3 phase calculation formula changes with line-to-line voltage, line-to-neutral voltage, star connection, and delta connection. For line-to-line voltage, use 1.732 x VLL x I x PF. For line-to-neutral voltage in a balanced star connection, use 3 x VLN x I x PF.

Total 3 Phase Power Formula

T

Total 3 phase power equals the sum of power in all three phases. For a balanced load, total power = 3 x phase voltage x phase current x PF. The same result is total power = 1.732 x line voltage x line current x PF.

Ptotal = PA + PB + PCBalanced: 3 x Vphase x Iphase x PF

3 Phase Power Calculation Formula

Tri

The 3 phase power calculation formula can calculate real power, apparent power, and reactive power. Apparent power is measured in KVA, real power is measured in kW, and reactive power is measured in kVAR. Reactive power causes circulating current in inductive and capacitive AC circuit loads.

Power TrianglekVA^2 = kW^2 + kVAR^2 Power FactorPF = kW / kVA Reactive PowerkVAR supports magnetic fields

Advantages of reactive power include magnetic field support in motors and transformers. Too much reactive power increases current, voltage drop, conductor heating, and power factor penalties.

3 Phase Calculator FAQs
What is the fastest 3 phase current formula?

The fastest 3 phase current formula is amps = watts / (1.732 x volts x power factor). Use line-to-line voltage for standard balanced three phase loads.

What is the difference between delta and wye configuration?

Delta configuration connects phase windings in a closed loop, while wye or star connection joins one end of each phase at a neutral point. Delta vs Wye configuration changes voltage relationships and neutral availability.

What is apparent power in three phase power?

Apparent power is total voltage-current capacity in KVA. Real power does useful work in kW, and reactive power supports magnetic and electric fields in kVAR.

Does power factor correction reduce current?

Yes, power factor correction can reduce line current for the same real power. Lower current reduces voltage drop, conductor heating, transformer loading, and utility penalties.
