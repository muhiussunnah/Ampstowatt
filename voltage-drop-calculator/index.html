Voltage Drop Calculator

A voltage drop calculator estimates voltage loss across a wire or cable run. Voltage drop happens when current in amps (A) flows through conductor resistance in ohms (Ω). The loss reduces load voltage, wastes power in watts (W), raises cable heat, and can make motors, LED strips, electronics, solar charge controllers, and low voltage lighting perform poorly.

Use this voltage drop calculator for DC, AC, single phase, 3 phase, 12V, 24V, 48V, 120V, 230V, 240V, wire size, cable size, copper, aluminum, armoured cable, XLPE cable, NEC, IEC, BS7671, DEWA, and project voltage drop reports.

What Is a Voltage Drop Calculator

A voltage drop calculator finds the voltage lost between a power source and a load. The calculator uses current, wire length, conductor resistance, material, circuit type, and source voltage to estimate voltage drop in volts and percentage.

Voltage drop calculators are used for residential branch circuits, extension cords, underground feeders, overhead lines, low voltage lighting, fire alarm circuits, PoE, PCB traces, automotive wiring, car audio, LED strip wiring, solar panels, medium voltage cables, HT cables, and HV cables.

CAL

How Voltage Drop Is Calculated

Voltage drop is calculated by multiplying current by conductor resistance over the circuit length. DC and single phase circuits use the outgoing and return path, so the formula uses 2 x I x R x L. A balanced 3 phase circuit uses the square root of 3 x I x R x L.

The key inputs are amps, volts, ohms per meter or per foot, one-way distance, copper or aluminum material, AWG or mm² wire size, temperature, power factor, parallel conductors, and derating.

FX

Voltage Drop Formula

The voltage drop formula for DC and single phase is Vdrop = 2 x I x R x L. The voltage drop formula for 3 phase is Vdrop = 1.732 x I x R x L. Voltage drop percentage is %Vdrop = (Vdrop / Vsource) x 100.

DC / 1 Phase: Vdrop = 2 x I x R x L
3 Phase: Vdrop = 1.732 x I x R x L

Use resistance in ohms per unit length and length in the same unit. For NEC circular mils, the common copper formula is VD = (2 x K x I x D) / CM for single phase, where K is conductor resistivity and CM is circular mil area.

WHY

Voltage Drop Calculation Explained

Voltage drop calculation shows how much source voltage is lost before power reaches the load. A 120V circuit with 4V drop delivers about 116V to the load. A 12V DC circuit with 1V drop delivers only 11V, which is a much larger percentage loss.

Voltage drop is not the same as amps, but amps cause voltage drop through resistance. Voltage drop is not power, but voltage drop creates power loss as heat. Power loss is Ploss = I² x R.

EX

Voltage Drop Calculation Example

A 20A load on a 230V circuit with 30m of 10 AWG copper has about 1.20V voltage drop. Using R = 0.000999 ohms per meter, Vdrop = 2 x 20 x 0.000999 x 30 = 1.1988V. Percentage drop = 1.1988 / 230 x 100 = 0.52%.

End voltage is 230V - 1.20V = 228.8V. This voltage drop calculation example is acceptable for most design targets.

DIST

How Do You Calculate Voltage Drop Over Distance

To calculate voltage drop over distance, multiply conductor resistance per meter or foot by the one-way distance and current. Use 2 x distance for DC and single phase circuits to include the outgoing and return conductor path.

Distance matters more in 12V, 24V, and 48V low voltage systems. Each lost volt is a larger percentage of the source voltage.

RUN

How to Calculate Voltage Drop Over a Distance

Calculate voltage drop over a distance by entering load current, source voltage, wire size, material, and one-way length into the calculator. Use AWG for North American wire and mm² for IEC or BS7671 cable schedules.

A voltage drop calculator over distance helps compare copper wire, aluminum cable, armoured cable, XLPE cables, and parallel runs before installation.

LEN

How to Calculate Voltage Drop Without Length

You cannot calculate real voltage drop without length unless total circuit resistance is known. Use Vdrop = I x Rtotal when the measured loop resistance is available. Use an estimated length only for early planning.

For an existing circuit, measure voltage at the source and at the load under operation. The difference is the actual voltage drop.

%

What Percent Voltage Drop Is Acceptable

Common acceptable voltage drop targets are 3% for branch circuits and 5% for total feeder plus branch circuits. Sensitive electronics, LED strips, fire alarm circuits, PoE, and solar DC systems may need tighter limits.

Acceptable voltage drop depends on equipment voltage tolerance, local code, project specification, and system type.

3/5

Is Voltage Drop 3 Or 5 Percent

Voltage drop is often designed around 3% for a final circuit and 5% for the total run. The 3% value is a common branch circuit target. The 5% value is a common feeder plus branch circuit total target.

Use the lower value when the load is sensitive, the circuit is low voltage, or the project specification is strict.

IMP

Is Voltage Drop Important

Yes, voltage drop is important. Low load voltage reduces performance and wastes energy. Motors can run hotter, LED strips can dim, inverters can alarm, electronics can reset, and long cable runs can waste power as heat.

Voltage drop matters most on long cable runs, high current loads, low voltage systems, aluminum cable, and high temperature installations.

CODE

Is Voltage Drop a Code Requirement

Voltage drop is often treated as a design recommendation, but some projects and jurisdictions make voltage drop a requirement. NEC guidance is commonly used in the USA, while IEC, BS7671, CEC, AS/NZS 3000, AS/NZS 3008, PEC, DEWA, and client standards can set required limits.

Use local rules for final design. A voltage drop calculation report should list source voltage, load current, cable length, wire size, material, temperature, installation method, standard used, and final percentage.

A

Using Voltage Drop to Calculate Current

Voltage drop can calculate current when total resistance is known. Use I = Vdrop / Rtotal. For a DC loop with known conductor resistance and distance, Rtotal = 2 x R x L.

This method is useful for checking a measured voltage drop against expected current, but load behavior can change when voltage falls.

A voltage drop calculator with resistance uses Vdrop = I x Rtotal. Resistor voltage drop, voltage drop through resistor, voltage drop over resistor, and Ohm's Law calculations all use the same relationship.

For a cable run, Rtotal comes from conductor resistance per length multiplied by circuit length. For parallel circuits, calculate equivalent resistance before using Ohm's Law.

FAQ

Voltage Drop Calculator FAQs

Voltage drop calculator FAQs answer the practical sizing questions users ask before choosing wire, cable, or conduit. Use the direct answers below for DC, AC, 3 phase, standards, motors, electronics, resistors, and solar panels.

Q1

What is voltage drop in electrical wiring?

Voltage drop in electrical wiring is the voltage lost as current flows through conductor resistance. More current, more distance, smaller wire, and higher resistance increase voltage drop.

Q2

How much voltage drop is allowed?

Common design limits allow 3% on a branch circuit and 5% total feeder plus branch circuit drop. Local NEC, IEC, BS7671, CEC, or project rules decide the final allowed value.

Q3

Is 3% voltage drop acceptable?

Yes, 3% voltage drop is acceptable for many final circuits and sensitive loads. Low voltage LED, solar, and electronics circuits may need lower drop.

Q4

Is 5% voltage drop acceptable?

Yes, 5% voltage drop is often acceptable as a total feeder plus branch circuit target. Check equipment tolerance before using 5% on motors, controls, or electronics.

Q5

How do you calculate voltage drop?

Calculate voltage drop by multiplying current by circuit resistance. Use Vdrop = 2 x I x R x L for DC and single phase, and Vdrop = 1.732 x I x R x L for balanced 3 phase.

Q6

How do you calculate voltage drop over distance?

Calculate voltage drop over distance by multiplying resistance per length by the cable run length and current. Use round-trip length for DC and single phase circuits.

Q7

What causes voltage drop?

Voltage drop is caused by conductor resistance and load current. Long distance, small wire size, high temperature, aluminum conductors, and poor connections increase voltage drop.

Q8

Does wire size affect voltage drop?

Yes, wire size affects voltage drop directly. Larger AWG or mm² cable has lower resistance and lower voltage drop.

Q9

Does temperature affect voltage drop?

Yes, temperature affects voltage drop. Conductor resistance rises when copper or aluminum gets hotter. Hot cable runs need temperature-aware calculations.

Q10

What is the voltage drop formula?

The voltage drop formula is Vdrop = 2 x I x R x L for DC and single phase, and Vdrop = 1.732 x I x R x L for 3 phase. Percentage drop is Vdrop / Vsource x 100.

Q11

How does voltage drop affect motors?

Voltage drop can make motors draw more current, lose torque, run hotter, and start poorly. Motor feeders should be checked at running current and starting conditions.

Q12

What is the best wire size for low voltage?

The best wire size for low voltage is the size that keeps drop within the target percentage at the real current and distance. 12V and 24V circuits usually need larger cable than mains circuits at the same wattage.

Q13

What is acceptable voltage drop for solar panels?

Acceptable voltage drop for solar panels is commonly 1% to 3% for efficient PV and battery cable design. The final target depends on array voltage, controller type, current, and project budget.

Q14

How does NEC define voltage drop?

NEC uses voltage drop guidance in informational notes, often referenced as 3% branch circuit and 5% total voltage drop. NEC ampacity and overcurrent rules still control safety sizing.

Q15

How does IEC calculate voltage drop?

IEC voltage drop calculations use current, length, conductor resistance, reactance, power factor, and cable size in mm². Manufacturer cable tables are commonly used for R and X values.

Q16

What is voltage drop in DC circuits?

Voltage drop in DC circuits is the voltage lost across the positive and negative conductors. Use Vdrop = 2 x I x R x L for a two-wire DC loop.

Q17

What is voltage drop in AC circuits?

Voltage drop in AC circuits is voltage lost through conductor impedance while alternating current supplies the load. Resistance, reactance, power factor, and phase type affect AC drop.

Q18

How does power factor affect voltage drop?

Power factor affects voltage drop in AC circuits. Current phase angle changes the resistance and reactance contribution. Low power factor loads often need more detailed impedance calculations.

Q19

What is voltage drop in a resistor?

Voltage drop in a resistor is current multiplied by resistance. Ohm's Law gives V = I x R, and power loss is P = I² x R.

Q20

Can voltage drop damage electronics?

Yes, voltage drop can damage or disrupt electronics when the load voltage falls below the required operating range. Low voltage can cause resets, dimming, errors, relay chatter, overheating, or failed starts.
